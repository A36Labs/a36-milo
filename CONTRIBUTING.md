# Contributing to A36 Milo

Thank you for contributing to A36 Milo.

A36 Milo is an open-source AI community manager for Telegram, developed by A36 Labs. We welcome contributions from developers, community builders, designers, researchers and open-source contributors worldwide.

## Ways to contribute

You can contribute by:

- Fixing bugs
- Improving documentation
- Adding language support
- Improving conversation quality
- Adding Telegram features
- Improving privacy and security
- Optimizing Cloudflare Worker performance
- Improving community engagement logic
- Adding tests
- Suggesting new features
- Reviewing pull requests

## Before contributing

Please:

1. Read the project README.
2. Search existing issues and pull requests.
3. Avoid creating duplicate issues.
4. Never include API keys, tokens or private credentials.
5. Keep changes focused on one problem or feature.
6. Follow the project Code of Conduct.

## Reporting bugs

Open a GitHub issue and include:

- A clear description of the issue
- Steps to reproduce it
- Expected behavior
- Actual behavior
- Relevant logs with secrets removed
- Cloudflare Wrangler version
- Screenshots when useful

Never expose:

TELEGRAM_BOT_TOKEN
TELEGRAM_WEBHOOK_SECRET
